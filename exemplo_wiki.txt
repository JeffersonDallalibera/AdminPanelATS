Manual de Uso do AdminPanelATS
Guia completo para utilizar todas as funcionalidades do sistema de painel administrativo

# Introdução
Bem-vindo ao AdminPanelATS! Este é um sistema completo de gerenciamento administrativo que combina a gestão de conhecimento através de wikis e o acompanhamento de tarefas em tempo real.

O sistema foi desenvolvido em PHP utilizando SQL Server como banco de dados, seguindo a arquitetura MVC para garantir organização e manutenibilidade do código.

# Funcionalidades Principais

## Dashboard
O dashboard é a página principal do sistema onde você encontra:
- KPIs (Key Performance Indicators) com as principais métricas
- Estatísticas de wikis e tarefas
- Visualização rápida de itens recentes
- Gráficos de distribuição de tarefas por status

## Geração de Wikis
A funcionalidade de geração de wikis permite:
- Upload de arquivos .txt formatados
- Parser automático do conteúdo
- Preview antes de salvar
- Organização hierárquica de seções
- Suporte a múltiplos níveis de seções (usando # e ##)

## Monitor de Tarefas
O monitor de tarefas oferece:
- Visualização em tempo real com AJAX
- Criação rápida de novas tarefas
- Atualização de status com um clique
- Filtros por status (pendente, em andamento, concluída)
- Estatísticas instantâneas
- Auto-atualização a cada 10 segundos

# Primeiros Passos

## Acessando o Sistema
1. Abra seu navegador
2. Acesse http://localhost/dashboard.php
3. Você será direcionado para o dashboard principal

## Criando sua Primeira Wiki
1. Clique em "Gerar Wiki" no menu
2. Prepare um arquivo .txt seguindo o formato especificado
3. Faça upload do arquivo
4. Revise o preview
5. Clique em "Salvar Wiki"

## Gerenciando Tarefas
1. Acesse "Monitor de Tarefas" no menu
2. Clique em "Nova Tarefa"
3. Preencha título, descrição e prioridade
4. Acompanhe o status em tempo real

# Formato de Arquivo TXT para Wikis
A primeira linha do arquivo é o título da wiki
A segunda linha é a descrição (opcional)

Seções principais começam com #
Subseções começam com ##

O conteúdo pode ter múltiplas linhas
E será formatado automaticamente

# Dicas e Boas Práticas

## Organização de Wikis
- Use títulos descritivos
- Organize o conteúdo em seções lógicas
- Mantenha as seções concisas
- Use subseções para detalhar informações

## Gerenciamento de Tarefas
- Defina prioridades adequadamente
- Atualize o status regularmente
- Use descrições claras
- Aproveite a auto-atualização para acompanhar mudanças

# Solução de Problemas

## Erro ao fazer upload
- Verifique se o arquivo é .txt
- Confira o tamanho máximo (5MB)
- Certifique-se de que o diretório de uploads tem permissão de escrita

## Tarefas não atualizam
- Verifique a conexão com o banco de dados
- Confirme que o JavaScript está habilitado
- Limpe o cache do navegador

# Conclusão
Este sistema foi desenvolvido para facilitar a gestão administrativa combinando documentação (wikis) e acompanhamento de trabalho (tarefas). 

Use as funcionalidades de forma integrada para maximizar sua produtividade!
